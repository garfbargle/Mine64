The audio heap is a game parameter, not a reservation. src/audio.c passes address and size to nuAuMgrInit itself. 320 KiB is the SDK default; this game's voice and DMA config needs about 73 KiB. Confirm with nuAuHeapGetUsed() first.

The RDP FIFO is the SDK's 128 KiB. Its size is baked into nusys.o, so halving it means rebuilding libnusys. With the fifo microcode a short buffer costs throughput, not correctness.
