29 KiB

Five of six microcodes stopped being linked. Since the world, wireframe and HUD passes were collapsed into one RSP task, only F3DEX2 is ever selected — the rest sat resident and never ran. src/ucode_stubs.c keeps NuSystem's table resolving without them.

64 KiB

Mine64 supplies its own RDP FIFO. The SDK's is 128 KiB and is the only symbol in its archive member, so defining it in src/rdp_fifo.c replaces it outright — no SDK rebuild. nuGfxInit registers the SDK's size constant rather than sizeof, so the real size has to be re-registered after it.

224 KiB

The audio heap is sized for this game. 320 KiB was the SDK default for a full sequence player; Mine64 runs four voices. src/audio.c reserves 88 KiB. That is still the SDK formula's estimate rather than a reading — the U diagnostic row reports what is actually used.

Still on the table

~64 KiB

The per-texture index is stored at full width. column_starts and staged_starts hold a 32-bit pointer per texture per slot, and most point at the same shared "nothing here" list. A block number plus a 16-bit offset would halve both — at the cost of one more indirection in the loop that already dominates a standing frame.

64 KiB

c_models spends 64 bytes per slot on a translation. Baking each column's offset into its vertices would delete the array and a matrix push per column per frame, but would weld every mesh to the render origin — a rebase would then mean a full remesh. Probably not worth it.

Not reclaimable

480 KiB

The window is bigger than the stream radius can fill. 32 × 32 slots, because slot lookup must be a mask; a radius of 12 spans 25 columns. So 399 slots of window_blocks and 78 KiB of per-slot tables can never be occupied. Spending it means more view distance, which costs frame time rather than RDRAM.

22 KiB
